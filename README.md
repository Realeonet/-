## Разговорник и переводчик: русский / иврит → испанский

Статическое веб-приложение без сборки. Откройте `index.html` через HTTPS
или `localhost` (микрофон не работает с `file://`).

- **Говорить:** нажмите на кнопку микрофона, скажите фразу (русский или иврит).
  Текст распознаётся и переводится на испанский автоматически.
- **Воспроизвести:** нажмите «▶ Воспроизвести по-испански», браузер озвучит перевод.
- **Разговорник:** готовые фразы по разделам. Переводятся офлайн, по нажатию на
  фразу или на ▶ рядом с ней.

Файлы:
- `index.html`, `styles.css` — интерфейс.
- `app.js` — распознавание речи (Web Speech API), перевод, озвучка.
- `phrases.js` — фразы разговорника (`ru`, `he`, `es`). Новые фразы добавляются сюда.

Перевод произвольного текста идёт через MyMemory API (бесплатно, без ключа, есть дневной лимит).
Распознавание речи и озвучка используют возможности браузера: в Chrome и Edge
распознавание работает, озвучка зависит от установленных испанских голосов.
