# Фотопересчёт товара

Одностраничное приложение для кладовщика: пересчёт товара по фотографиям с телефона.
Работает в браузере, установка не нужна — достаточно открыть `index.html`.

## Что умеет

**По фото (ИИ).** Три вида снимков:

| Снимок | Зачем |
|---|---|
| Общий план (обязательно, 1–4 фото) | всё место целиком: полка, паллета, ящик |
| Вблизи (по желанию) | торец стопки, один ряд, слой россыпи — видно, сколько штук в ряду и как глубоко |
| Эталон, 1 единица (по желанию) | модель узнаёт товар и его размер; лучше рядом с рукой или рулеткой |

Плюс подсказки: название, как лежит (коробки, паллета, полка, россыпь, ящик), сколько штук в коробке,
что не видно на фото, сколько числится по системе.

В режиме «Точно» снимки считаются тремя независимыми методами:

1. **Прямой счёт**: каждая видимая единица ряд за рядом, плюс скрытые там, где структура это однозначно показывает.
2. **Структура укладки**: по фронту × вглубь × ярусы × штук в коробке, с поправками на пустые места.
3. **Объём**: габариты места / размер единицы × плотность укладки (полезно для россыпи).

Опция «Мелкий товар» отдельно считает общий план по четвертям: каждая четверть отправляется
в более высоком разрешении, и мелкие предметы теряются реже.

**Отметить.** Ручной подсчёт: тапаете по каждой единице на фото, ставится пронумерованная метка.
Можно умножить на число слоёв и на штук в метке. Пригодится, чтобы проверить ИИ.

**Калькулятор.**
- По укладке: ряды × глубина × ярусы × штук в коробке + россыпь − пустые места.
- По весу: самый точный способ для россыпи (вилки, ложки, крепёж). Взвесьте 10–20 штук, затем всё целиком.

**История.** Результаты сохраняются на устройстве, их можно скопировать одним списком.

## Как считается погрешность

Итоговое число — медиана оценок всех методов. Погрешность ± складывается так:

```
погрешность = max( минимум_для_типа,  √(расхождение² + неуверенность²) )
```

- **расхождение** — половина разброса между методами (max − min) / 2;
- **неуверенность** — медиана полуширины диапазона, который модель дала для скрытых частей (90 %);
- **минимум для типа выкладки** — нижняя граница, ниже которой оценке по фото верить нельзя:

| Тип выкладки | Минимум | Типичная погрешность на практике |
|---|---|---|
| Отдельные предметы, все видны | 0 % | ±0–2 шт |
| Ровные ряды коробок | 2 % | ±2–5 % (при видимом торце стопки) |
| Стопки | 4 % | ±4–8 % |
| Смешанная укладка | 8 % | ±8–15 % |
| Россыпь, куча | 12 % | ±12–30 % |

Пример: 240 шт в коробках, методы дали 232 / 240 / 248 → расхождение ±8, модель ±12,
минимум 2 % = ±5 → **240 ± 14 шт** (вероятно 226–254).

Метка надёжности: «Надёжно» — погрешность ≤ 5 % и уверенность ≥ 70 %; «Ориентир» — ≤ 15 %;
иначе «Грубая оценка». Если указано количество по системе, приложение покажет, попадает ли оно в диапазон.

Это оценки, а не гарантия. Для инвентаризации с жёсткими допусками используйте вес или ручной счёт.

### Как сузить диапазон

- Снимайте так, чтобы был виден торец стопки или ряд в глубину: скрытые ряды — главный источник ошибки.
- Для коробок откройте одну и сфотографируйте содержимое, либо укажите «штук в коробке».
- Для россыпи взвесьте (вкладка «Калькулятор → По весу») или разровняйте в один слой.
- Снимайте при хорошем свете, без бликов, держите телефон ровно.

## Подключение к Claude

- **Внутри приложения Claude** (артефакт): подсчёт идёт через ваш аккаунт Claude, ключ не нужен.
  При первом подсчёте страница спросит разрешение отправлять фото.
- **Отдельно** (файл, GitHub Pages и т. п.): впишите ключ Anthropic API в «Настройки подключения».
  Ключ хранится только в браузере этого устройства. Модель по умолчанию — Claude Opus 5.5,
  можно переключить на Claude Sonnet 5.5 (быстрее и дешевле).
  Включён серверный фолбэк (`fallbacks: "default"`): если модель отклонит запрос, его обработает запасная модель.

Вкладки «Отметить», «Калькулятор» и «История» работают без интернета и без ИИ.
