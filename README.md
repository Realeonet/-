# Личный учёт инвестиций (замена Stock Analysis)

Приложение для личного учёта: счета, пенсионные накопления (קרן פנסיה, קרן השתלמות, קופת גמל, ביטוח מנהלים), оценка баланса по дням и сверка с официальной доходностью. Интерфейс на русском, термины — на иврите.

**Приватность:** все данные хранятся локально в SQLite (папка `DATA_DIR`). Наружу уходят только запросы котировок — тикеры и даты. Суммы, счета и позиции никуда не отправляются.

> Это инструмент для личного учёта, не инвестиционный совет. Налоговые расчёты ориентировочные — сверяйте с налоговым консультантом.

---

## 1. Установка (Windows)

Нужен Python 3.11 или новее (python.org, при установке отметьте «Add python.exe to PATH»).

1. Откройте папку проекта.
2. Запустите `install.bat`. Он создаст окружение `.venv`, установит библиотеки и скопирует `.env.example` в `.env`.
3. Откройте `.env` и при необходимости задайте `DATA_DIR` и `BACKUP_DIR` (см. раздел «Бэкап»).

## 2. Запуск

Запустите `start.bat`. В консоли появится адрес, например `http://localhost:8501`.

- С того же компьютера: `http://localhost:8501`
- С телефона или другого компьютера дома: `http://<IP ноутбука>:8501`. IP узнаётся командой `ipconfig` (строка «IPv4-адрес»).

**Брандмауэр Windows.** Чтобы телефон видел приложение, разрешите порт 8501 в частной сети. В PowerShell от администратора:

```powershell
New-NetFirewallRule -DisplayName "Finance 8501" -Direction Inbound -Protocol TCP -LocalPort 8501 -Action Allow -Profile Private
```

Сеть должна быть помечена как «Частная» (Параметры → Сеть → Свойства подключения).

**Важно:** приложение работает, только пока компьютер включён и Streamlit запущен. Оно слушает только домашнюю сеть, наружу в интернет не выставляется. Для постоянной работы на домашнем компьютере поставьте в автозагрузку ярлык на `start.bat` и отключите сон при подключении к сети.

**Первый запуск:** приложение попросит задать пароль (минимум 8 символов). Пароль хранится как хэш scrypt, сам пароль нигде не записывается.

## 3. Обновление

1. Остановите приложение (закройте окно `start.bat`).
2. Обновите код (`git pull` или скачайте новую версию в ту же папку).
3. Запустите `install.bat` (он обновит библиотеки, если они изменились), затем `start.bat`.

Данные не трогаются: база лежит в `DATA_DIR`, а не в папке с кодом.

## 4. Бэкап и перенос на другой компьютер

Бэкап — зашифрованный файл `.fbk`. Он содержит все счета, историю балансов и официальные данные. Шифрование: Fernet, ключ выводится из парольной фразы через scrypt. Без парольной фразы файл не открыть, поэтому фразу храните отдельно.

**Создать бэкап:** раздел «Бэкап и восстановление» → парольная фраза → «Создать бэкап». Файл попадает в папку `BACKUP_DIR`. Если она не задана — в `DATA_DIR/backups`.

**Рекомендуемая схема:** `BACKUP_DIR` указывает на папку, которую синхронизирует Google Drive (например, `D:\G-Drive Mirror\finance-backups`). Так бэкап сам уходит в облако Google, а сама живая база остаётся локально. **Не кладите `DATA_DIR` внутрь синхронизируемой папки:** SQLite и синхронизация конфликтуют и могут повредить базу.

**Восстановление или перенос:**
1. На новом компьютере выполните шаги из раздела 1.
2. Скопируйте `.env` (или заполните `BACKUP_DIR` заново).
3. Запустите приложение, в разделе «Бэкап и восстановление» загрузите файл `.fbk`, введите парольную фразу, подтвердите замену данных.

Восстановление заменяет все данные в базе. Перед восстановлением сделайте свежий бэкап текущей базы.

**Рекомендация:** делайте бэкап после каждого заметного изменения (новый счёт, импорт, обновление баланса).

## 5. Пенсионный модуль

### Модель счёта

| Поле | Что значит |
|---|---|
| Владелец | я / Люба |
| Тип продукта | קרן פנסיה, קרן השתלמות (штальмут), קופת גמל, ביטוח מנהלים |
| Управляющая компания | свободный ввод, например Migdal, Menora, Phoenix, Harel, Clal, Altshuler, More, Meitav |
| Трек | из списка (см. ниже) или «אחר» с собственным названием |
| Баланс, ₪ и дата баланса | вводятся вручную, дата фиксируется |
| Веса классов, % | израильские акции, зарубежные акции, израильские облигации, зарубежные облигации, кэш. Сумма ровно 100 |
| Хедж валюты, % | доля хеджирования зарубежной части, по умолчанию 0 |

### Треки и пресеты

Пресеты задаются в `config/pension.toml`. Трек «S&P 500» подставляет 100% зарубежных акций и тикер `^GSPC`. Остальные треки (מניות, כללי, по возрасту, אחר) веса не получают автоматически — их вводите вручную или берите из импорта состава. Если веса старше 45 дней, приложение показывает предупреждение.

### Как считается оценка

Для каждого дня, по которому есть котировки:

- Израильские классы — в шекелях: `r = доходность индекса`.
- Зарубежные классы — в долларах, пересчёт в шекели:
  `r_ILS = (1 + r_USD) × (1 + r_FX × (1 − hedge)) − 1`, где `r_FX` — изменение USD/ILS за день.
- Дневное изменение портфеля: `Σ(w_i × r_i)`, где `w_i` — доля класса.
- Оценка баланса: `баланс × Π(1 + дневное изменение)` начиная с даты баланса.

Всё считается в `Decimal`, округление только при показе. Результат всегда подписан как **«ОЦЕНКА, не официальная доходность фонда»**.

Прокси по умолчанию (`config/pension.toml`):

| Класс | Тикер Yahoo | Примечание |
|---|---|---|
| Израильские акции | `^TA125.TA` | TA-125. **Проверить символ.** Тикер самой биржи TASE не используется |
| Зарубежные акции | `ACWI` (или `^GSPC` для трека S&P 500) | iShares MSCI ACWI, в USD |
| Зарубежные облигации | `AGG` | Не было в ТЗ — предложено. **Проверить** |
| Израильские облигации | нет | Бесплатного тикера нет: доходность 0 и предупреждение. Оценка будет занижена |
| Кэш | 0 | |
| Курс USD/ILS | `USDILS=X` | **Проверить** |

Тикеры меняются в `config/pension.toml` без правки кода.

### Сверка с официальными данными

Раздел «Импорт официальных данных». Формат CSV:

```
period,return_pct,israel_equity_pct,foreign_equity_pct,israel_bonds_pct,foreign_bonds_pct,cash_other_pct
2026-01,1.23,40,30,20,5,5
```

- `period` — `YYYY-MM`, `MM/YYYY` или дата.
- `return_pct` — доходность за месяц в процентах. Запятая или точка — обе работают.
- Колонки состава необязательны. Если они заполнены во всех пяти, то:
  - они сохраняются в официальной записи месяца;
  - для ручного трека последний состав становится текущими весами (дата весов — конец месяца).
- Имена колонок меняются в `[columns]` файла `config/pension.toml`.

Отчёт сверки показывает: оценка за месяц, официальная доходность и разницу в процентных пунктах (tracking error).

Ссылки на данные: [פנסיה-נט](https://www.pensionet.mof.gov.il) и [גמל-נט](https://www.gemelnet.mof.gov.il) (Минфин). Публичный API на data.gov.il **не проверялся**. Пока импорт делается через CSV.

### Обновление баланса

В карточке счёта — «Обновить баланс». Вводите значение из отчёта фонда или личного кабинета (источник «отчёт/кабинет»). Оценка начинается заново от новой даты. Все официальные значения видны на графике как точки.

### Ограничения

- Оценка не учитывает комиссии фонда, перераспределение, реальные сделки и налоги.
- Yahoo Finance через `yfinance` — неофициальный источник. Он может сломаться без предупреждения. Тогда карточка покажет ошибку, а баланс останется.
- Веса считаются постоянными на всём периоде. Если фонд ребалансирует, сверка это покажет.

## 6. Тесты

```
.venv\Scripts\activate
python -m pytest
```

Тесты покрывают формулы (хедж, валютный пересчёт, сумма 100%, пороги), оценку по котировкам на синтетических рядах, импорт CSV, бэкап (шифрование, неверная фраза, восстановление) и пароль. Сетевых запросов в тестах нет.

## 7. Структура проекта

```
streamlit_app.py      интерфейс
app/
  config.py           .env и загрузка config/pension.toml
  db.py               модели SQLite
  security.py         пароль (scrypt)
  backup.py           зашифрованный экспорт/импорт
  adapters/prices.py  источники котировок (yfinance — меняется заменой класса)
  domain/pension.py   формулы (чистые функции)
  services/pension.py оценка счетов, сверка
  importers/pension_csv.py  импорт официальных данных
config/pension.toml   треки, пресеты, тикеры, колонки CSV
tests/                тесты
install.bat / start.bat
```
