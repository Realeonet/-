# תגבור - אנגלית ותנ״ך

אפליקציה קטנה לתגבור בכיתה ה׳, בנויה לילדים עם קשיי קריאה וכתיבה וקשב (ADHD).

## איך מפעילים

1. פותחים את הקובץ `index.html` בדפדפן (Chrome, Safari, Edge). אין צורך בהתקנה או באינטרנט מלבד הפונטים.
2. אפשר גם להעלות את התיקייה לאתר סטטי (למשל GitHub Pages) ולפתוח מהטלפון.

## מה יש בפנים

- **אנגלית**: שמיעת מילה ובחירת המשמעות בעברית, בניית האיות מאותיות (בלי צורך לכתוב), והשלמת משפטים עם רמז בעברית.
- **תנ״ך**: סיפורים קצרים עם הקראה בקול, ושאלה אחת על כל סיפור. הסיפורים: בריאת העולם, נח, יוסף, משה, דוד וגלית ועשרת הדיברות.
- **כיף**: כוכב על כל תשובה נכונה בניסיון הראשון, תארים שמתקבלים לפי מספר הכוכבים, וכפתורי הקראה בכל מקום.
- **ADHD**: סיבובים קצרים של 5 שאלות, סרגל התקדמות, ואחרי כל סיבוב הפסקת תנועה עם טיימר של דקה.
- **למבוגרים**: מסך שמראה כוכבים, סיבובים שהושלמו, ורשימת מילים ושאלות לחזרה בבית.

## הוספת תוכן

כל התוכן נמצא בתחילת הקובץ `index.html`, בשלושה מערכים:

- `WORDS`: מילים באנגלית עם תרגום ואימוג׳י.
- `SENTENCES`: משפטים עם מילה חסרה (`___`), התשובה (`a`) ותרגום (`he`).
- `BIBLE`: סיפורים עם כותרת, אימוג׳י, טקסט, שאלה, אפשרויות ותשובה (`a`).

אפשר להוסיף פריטים באותו פורמט. בנוסף, כל ההתקדמות נשמרת בדפדפן של המכשיר הזה בלבד, ואפשר לאפס אותה ממסך "למבוגרים".
